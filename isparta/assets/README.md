# Isparta profil logosu

`logo-profile.jpg`, kullanıcının referans alınmasını onayladığı mevcut
`@ispartaofficial` profil logosudur. Orijinal 1080×1080 dosya korunur.
Yeni logo üretimi veya sosyal profil değişikliği yapılmamıştır.

Kart şablonu yalnız çevredeki boş gradyan alanını kendi yerleşiminde kırpar;
bütün gül simgesi ve yazı korunur. Yerel önizleme sahnesi bu klasörde değildir
ve gerçek etkinlik fotoğrafı olarak kullanılmaz.
